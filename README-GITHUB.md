# 設備現場マネージャー

機械設備工事の現場監督向けに作成した、スマートフォン・PC対応のPWAです。

## 主な機能

- ToDo管理：追加、編集、完了、進捗「前・中・後」、期限超過表示
- 工程計算：歩掛、数量、人数、稼働率、配管径・ダクトサイズ補正
- 配管材選定：用途別候補、お気に入り、異種管変換、パッキン、吊りピッチ
- 区画貫通：管種・壁床・保温条件から工法候補を表示
- 設備計算ツール、施工ルール、建築取り合い、打合せ資料
- 工事用語辞典、設備機器解説、施工要領、施工手順動画
- PDF資料登録・本文検索
- AI質問、AI議事録、録音保存期限・同意確認
- 現場単位のデータ分離、権限、操作履歴、バックアップ
- PWA：ホーム画面追加、オフライン用画面、アプリアイコン

## 技術構成

- React 19
- Next.js 16互換構成
- Vinext / Vite
- Cloudflare Workers
- Cloudflare D1（データベース）
- Cloudflare R2（PDF・録音ファイル）
- Drizzle ORM

## GitHubへ配置する

1. このフォルダーの中身をGitHubの新規リポジトリへアップロードします。
2. Node.js 22.13以上を用意します。
3. プロジェクト直下で次を実行します。

```bash
npm ci
npm run dev
```

本番ビルド：

```bash
npm run build
```

## PWA

PWA用ファイルはすでに含まれています。

- `public/manifest.webmanifest`
- `public/service-worker.js`
- `public/offline.html`
- `public/icons/`
- `app/pwa-setup.tsx`

HTTPS環境へ配置すると、対応ブラウザーからホーム画面・デスクトップへ追加できます。

## データベース

テーブル定義は `db/schema.ts`、マイグレーションは `drizzle/` に入っています。

現在の登録データは次に収録しています。

```text
data-export/registered-data.json
```

このJSONには、ToDo、工程、材料、区画貫通、設定、議事録メタデータなどが含まれます。公開GitHubへ登録すると現場情報が第三者に見えるため、登録データを含む状態では必ず非公開リポジトリを使用してください。

PDF・録音ファイル本体はCloudflare R2側に保存されるため、JSONにはファイル名・保存キー等のメタデータだけが含まれます。

## 外部へ独立配備するとき

`.openai/hosting.json` は現在のChatGPT Sites環境の識別情報を含みます。現在のサイトをSitesで継続更新する場合はそのまま使用できます。別のCloudflare環境へ独立配備する場合は、次を新規環境に合わせて設定してください。

- D1バインディング：`DB`
- R2バインディング：`BUCKET`
- 必要に応じて `OPENAI_API_KEY`
- 必要に応じて `OPENAI_MODEL`

ログイン利用者は、現在はホスティング環境から渡される `oai-authenticated-user-email` を使用しています。別サービスへ移す場合は、`lib/request-context.ts` の認証部分を利用する認証サービスに置き換えてください。

## 情報の取り扱い

施工条件や製品仕様は変更される可能性があります。法令、設計図書、特記仕様書、承認図、所轄官庁および採用メーカーの最新版を優先してください。

AI回答・歩掛・支持材・勾配・区画貫通の表示は施工判断の補助です。施工確定前に有資格者・監理者・メーカー資料で照合してください。
